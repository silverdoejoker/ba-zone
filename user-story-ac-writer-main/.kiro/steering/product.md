# Product: User Story & AC Writer

A Kiro/Claude AI skill developed by **Phúc NT** at **BA Zone** (Vietnamese BA/PO community) to help Business Analysts and Product Owners write high-quality User Stories and Acceptance Criteria.

## Core Purpose
Generate, refine, and validate User Stories + Acceptance Criteria that meet INVEST criteria and use Gherkin (Given-When-Then) format — output ready for dev estimation and QA test case writing.

## Three Operating Modes
- **Mode A – Write new**: Generate US + AC from a feature description
- **Mode B – Refine**: Review and improve an existing US/AC
- **Mode C – Add AC**: Supplement an existing User Story with additional AC

## Primary Domain
EdTech / Digital School products (e.g., course enrollment, mentor booking, certificates, live classes, B2B enterprise accounts, community forums).

## Quality Standards
- **INVEST** compliance: Independent, Negotiable, Valuable, Estimable, Small, Testable
- **Minimum 3 AC per story**: happy path + edge case + negative/error path
- Persona must be specific (never generic "user")
- AC must be measurable — no vague terms like "fast", "user-friendly"
- No implementation details (no API names, DB schemas, UI pixel specs)

## Out of Scope
PRD/URD/SRS writing, detailed technical test cases, formal Use Cases, business rules generation.
